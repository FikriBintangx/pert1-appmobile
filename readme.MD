# pertemuan 1

saya mempelajari dasar penggunaan dart untuk membuat data product.

pada pertemuan 1 saya mempelajari beberapa tipe data seperti string, int, double, bool, datetime, dan list string.

contoh kode yang saya pelajari:

```dart
void main() {
  String productName = 'Kopi Susu';
  int stock = 15;
  double price = 18000.0;
  bool isAvailable = true;
  DateTime updatedAt = DateTime.now();

  List<String> ingredients = ['Kopi', 'Susu'];

  print('Produk: $productName');
  print('Stok: $stock');
  print('Harga: Rp$price');
  print('Tersedia: $isAvailable');
  print('Update: $updatedAt');
  print('Bahan: $ingredients');
}
```

string digunakan untuk menyimpan data berupa teks seperti nama product.

int digunakan untuk menyimpan angka bulat seperti jumlah stock.

double digunakan untuk menyimpan angka seperti harga product.

bool digunakan untuk menentukan kondisi true atau false, contohnya untuk mengetahui apakah product tersedia.

datetime digunakan untuk menyimpan tanggal dan waktu.

list string digunakan untuk menyimpan beberapa data teks dalam satu variable, seperti daftar bahan product.

saya juga mempelajari cara mengubah nilai pada variable dan menampilkan data menggunakan print().

dari pertemuan 1 ini saya memahami dasar penggunaan variable dan tipe data pada dart untuk membuat sebuah data product sederhana.
